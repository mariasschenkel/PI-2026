# InclusIA

### Tecnologia e acessibilidade para uma comunicacao mais inclusiva

O **InclusIA** e um projeto desenvolvido para facilitar a comunicacao de pessoas com deficiencia intelectual, necessidades especificas ou dificuldades de comunicacao verbal.

A plataforma utiliza recursos visuais, sonoros e ferramentas de acessibilidade para tornar a comunicacao mais simples, intuitiva e inclusiva, contribuindo para a autonomia dos usuarios em diferentes situacoes do cotidiano.

O projeto tem como objetivo utilizar a tecnologia como ferramenta de inclusao social, promovendo acessibilidade e novas possibilidades de comunicacao.

## Objetivo

Desenvolver uma aplicacao web acessivel que auxilie pessoas com dificuldades de comunicacao a expressarem suas necessidades, preferencias e mensagens por meio de recursos visuais e sonoros.

## Funcionalidades

- **Comunicacao visual:** utilizacao de imagens para facilitar a expressao de necessidades e mensagens.
- **Recursos de audio:** reproducao de sons e mensagens por meio de botoes interativos.
- **Interatividade:** execucao de funcionalidades por meio de eventos de clique e interacao com elementos da interface.
- **Acessibilidade visual:** botoes grandes, textos em letras maiusculas e elementos que facilitam a navegacao.
- **Integracao com VLibras:** recurso de acessibilidade para traducao de conteudo para Libras.
- **Cadastro de usuarios:** interface para cadastro e gerenciamento de informacoes.
- **Processamento de dados:** utilizacao de PHP para processamento no servidor e integracao com banco de dados.

## Tecnologias utilizadas

| Tecnologia | Finalidade |

| CSS3 | Estilizacao e layout da interface |
| JavaScript | Interatividade e manipulacao de eventos |

| VLibras | Recurso de acessibilidade em Libras |
| Git | Controle de versao |

## Acessibilidade

A acessibilidade e um dos principais requisitos do InclusIA. A interface foi pensada para reduzir barreiras de comunicacao por meio de elementos visuais intuitivos, botoes de facil identificacao e recursos de audio.

O projeto busca proporcionar uma experiencia de navegacao simples, considerando diferentes necessidades e formas de comunicacao.
